> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Unattended-overnight rules: never push, commit per task, suite green (the one planned freeze window called out), stop cleanly on BLOCKED. Branch: `adqs-bds`.

**Goal:** Add ADQS, the questionnaire analysis dataset — the package's first derived analysis parameter (MOOD SCALE total) alongside per-item records — as the seventh ADaM dataset.

**Architecture:** Items are the ADEG BDS clone (AVAL = QSSTRESN, carried ABLFL); the total is spec-driven via a new optional `totals` table (`src_items` + declared range), computed generically in `derive_adqs()` with the all-items-present rule, baseline-derived at the item-baseline visit. The validator recomputes the total from SDTM QS instead of trusting the build.

**Tech Stack:** unchanged. **Spec:** `docs/superpowers/specs/2026-09-06-adqs-bds-design.md`. Templates: `R/adam-adeg.R` (items), `R/adam-advs.R` (BDS tail), `R/validate-adam.R:455-620` (ADVS checks) + `R/validate-adam.R` ADEG block.

### Task 2: `derive_adqs()`

**Files:** Create `R/adam-adqs.R`, `tests/testthat/test-adqs.R`; `R/globals.R` (only undeclared bare names — check `MOS01`-style names appear only via `src_items` parsing).

- [ ] Failing tests first (probe the built QS before pinning — the QS feature's deterministic item arithmetic is documented in the QS design doc): items = one row per subject-visit per spec$bds AQS param; AVAL = QSSTRESN; item ABLFL = QSBLFL, item ANRIND all NA, ANRLO/ANRHI NA; NOT-DONE visits produce no rows; **MOSTOT** = sum of the visit's items (probe exact totals), present exactly where all items are present; total ABLFL = "Y" at the visit where item QSBLFL == "Y" (and only there); total BASE/CHG/PCHG via shared rules (baseline total row: CHG/PCHG NA; screen failures: no item baseline → BASE/CHG/PCHG NA); total ANRIND LOW/NORMAL per the declared 4–12 range (probe: both classes occur); ADT = dtc_date(QSDTC); ADY = derive_dy_d recomputed in-test from pinned dates; all-subjects key uniqueness; interface order pin.
- [ ] Implement `derive_adqs(qs, adsl, spec)`:
  - items: clone the ADEG body (`R/adam-adeg.R`) — `filter(!QSSTAT %in% "NOT DONE")`, join `spec$bds` AQS rows on QSTESTCD, `ABLFL = QSBLFL`, `ADT = dtc_date(QSDTC)`, `ADY = derive_dy_d(ADT, TRTSDT)`, `.rule_chg/.rule_pchg/.rule_anrind`, PARAM = QSTEST.
  - totals: for each `spec$totals` row of the domain, per (USUBJID, VISITNUM): `AVAL = sum(items)` only when `!anyNA`; `ABLFL = "Y"` where that visit carries an item QSBLFL == "Y"; then the same BDS tail (BASE join, CHG/PCHG, ANRIND from the totals row's declared range, PARAM/PARAMN from the table).
  - bind, `arrange(USUBJID, PARAMN, AVISITN)`, apply_labels (ADVS label set; PARAMN "Parameter (N)").
